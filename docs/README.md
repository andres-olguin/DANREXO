## 5. Política breve de orden

- El README raíz tiene que explicar **qué es, qué existe, qué falta y cómo probarlo**, no copiar cada informe de investigación.
- Documentos vigentes: indicar fecha de corte, propietario, tipo de evidencia y estado real.
- Investigación heredada: conservar autoría, fuente y contexto; marcar `HISTÓRICO` si los compromisos, equipos o fechas no siguen vigentes.
- Propuestas de eliminación: clasificar en `conservar / consolidar / archivar / eliminar tras validar`; jamás borrar por apariencia sin comprobar referencias, tests, permisos y propiedad intelectual.
- Archivos de código, esquemas de DB, APIs, workflows y habilidades de agente requieren revisión separada de dependencias.
